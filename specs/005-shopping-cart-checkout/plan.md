# Implementation Plan: Shopping Cart & Checkout Flow

**Branch**: `[feature/005-shopping-cart-checkout]` | **Date**: 2026-07-05 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `/specs/005-shopping-cart-checkout/spec.md`

## Summary

Completar el flujo completo de compra desde el carrito hasta la confirmación de pedido utilizando componentes React y servicios del backend en Express/Prisma, implementando una simulación local de pago para estabilizar la conversión del ecommerce sin depender de APIs de terceros.

## Technical Context

**Language/Version**: TypeScript (Node.js 20+, React 18+)

**Primary Dependencies**: React (Frontend), Express, Prisma Client (Backend), Zod (Validation), react-hook-form (Forms)

**Storage**: PostgreSQL (via Prisma) - Reutilizando modelos existentes (Cart, CartItem, Order, OrderItem, Product).

**Testing**: N/A (Manual tests as described in quickstart.md)

**Target Platform**: Web Browser / Node.js Backend

**Project Type**: Fullstack Web Application (Vite + Express)

**Performance Goals**: Cart interactions must instantly update the UI optimistically without blocking the user interface.

**Constraints**: Local checkout simulation (no Stripe/PayPal integrations), synchronous stock validation.

**Scale/Scope**: Ecommerce checkout flow for a single user transaction at a time.

## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- **Is the tech stack respected?** Yes. Reusing React, Express, and Prisma.
- **Is the architecture respected?** Yes. Standard MVC-like controller pattern on backend and component pattern on frontend.
- **Are we avoiding new dependencies?** Yes. Payment will be simulated without external libraries.
