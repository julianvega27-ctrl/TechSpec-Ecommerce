# Quickstart Validation Guide

1. Ensure the backend is running (`npm run dev` in `backend`).
2. Ensure the frontend is running (`npm run dev` in `frontend`).
3. Log in as an Admin user.
4. Navigate to the Admin Dashboard (`/admin/dashboard`). Verify statistics cards show numeric values.
5. Navigate to Home Settings (`/admin/settings`). Change the title and save.
6. Open the public home page (`/`) in a new tab. Verify the new title is displayed immediately.
